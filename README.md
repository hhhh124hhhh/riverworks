# 山海拾遗

在古典山水与发光电路交错的河谷中，操控一台可拆装、可变形的小机器人。

Windows 双击 `Play.cmd` 进入游戏。也可以在本目录运行 `node serve.cjs` 后打开 `http://127.0.0.1:4177/`。用支持 WebGL 2 的浏览器。Three.js 和游戏文件都在项目目录，启动无需联网。

## 操作

- 点击可通行的地面或水面前往目的地，按住拖动转镜头，滚轮调整远近。手机上可点地面或水面，也可长按左下角的方向按钮。桌面仍支持 **WASD** 和方向键。
- **1** 步行，**2** 履带，**3** 变成小舟，**4** 展开云翼。新存档需要先找到当康山地轮、文鳐浮舟骨、应龙云翼和旋龟渊甲，零件不按固定顺序解锁。
- 云翼用 **空格** 升高、**C** 降低。浮岛瀑布下的上升气流也会托起云翼。取得渊甲后，小舟用 **C** 下潜、**空格** 上浮。靠近低岸才可以上下水。
- 夔牛雷泽的涟漪会推动小舟加速；九尾会转头看向靠近的行人。
- **E** 互动，**Q** 拆装，**M** 地图，**B** 山海异闻，**V** 切换视角，**H** 沉浸，**Esc** 设置。
- **Shift + E** 或点「换唱片」在留声机旁换唱片。可在设置中导入一首本地音乐供本次游玩使用。
- 渡灯可以装在机身或拿在手上，也可以借给夜渡的灯桩。回声芯可以留在山脊为风车供电，两件模块都能取回。
- 位置、模块状态、地标到访记录、设置和工坊便笺保存在同一浏览器。需要返回工坊时，使用设置里的「回工坊」。

## 地图

拾遗工坊、文鳐古渡、青丘松谷、白泽水巷、应龙山脊、旋龟汀洲、扶桑驿站、天狗望楼。每处地标都能在地图上选择并获得方向提示。

## 山海异闻

世界中有十五处可发现的山海异闻，分布在步行、履带、水面、水下和高空，也有只在夜晚出现的内容。青丘九尾、白泽、夔牛、北冥鲲影、扶桑和建木等都有实体场景。按 **B** 查看线索与记录，发现后地图会留下青色方块。

## 工坊支线

工坊门外的阿檐会介绍工坊修理。走近各地居民即可交谈。打开「委托」或按 **J** 可追踪委托，并给当前目标指路。

- 步行形态可以操作松谷的三道闸。履带用绞盘送小满和铜线盘到东街，小舟能拖回航标和靠近汀洲的网绳。
- 牵引时给载物留出转弯空间，界面会显示剩余距离和拖绳状态。载物卡住时，可以回头松绳，从另一侧绕过。委托里也能把载物重置到起点。
- 修好的路线会留在地图上：长街修线车、枫桥夜船和松谷水流会持续运转，不再只是任务打勾。
- 五处工坊修理完成后，到驿站发报，再去望楼点亮归航灯。回工坊交代这一路的修理。

## 涨水夜的最后一班渡

在「委托」中打开夜渡，或去汀洲西岸查看求助铃。可以划船接荷生、用浮板搭桥，或拆下回声芯组装报讯小车。点地面或用方向键驾驶小车，到了报讯杆按互动。救援结果存档，搭好的浮桥可以继续通行。
